# Battlezone (1980) - JavaScript recreation

A faithful browser recreation of Atari's original 1980 vector arcade game
Battlezone: first-person tank combat on a wireframe battlefield, with the
radar, periscope reticle, enemy tanks, supertanks, guided missiles, saucers,
the erupting volcano, the cracked-screen death, and the high score table.

Play with a Bluetooth / USB gamepad (two-stick tread control like the arcade
cabinet) or the keyboard.

See `docs/` for the design spec, implementation plan and reference notes on
the original game.
